## 📊 System at a Glance

### Navigation
```
Flow: 1.1 → 1.2 → 2.1 → ... → 14.3 → Summary
Back: Summary → 14.3 → ... → 2.1 → 1.2 → 1.1 → Landing
```

### Budget
```
Format: eventServicesMemory { eventType: {services, totalPrice} }
Calculation: Sum of all totalPrice values (no duplication)
Persistence: Maintained across all navigation
```

### Key Numbers
- **14 Steps** (1.1 through 14.3)
- **13 Events** (Wedding through Album)
- **6 Services** (Photo, Video, Candid, Video, Drone, Audience)
- **2 Duration Events** (Pre-Wedding, Post-Wedding)
- **~3 KB** memory for full quote
- **0 ms** navigation delay
